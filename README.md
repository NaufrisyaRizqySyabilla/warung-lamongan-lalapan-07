# warung-lamongan-lalapan-07
Website Pemesanan dan Pengelolaan Menu pada Warung Lamongan Lalapan 07.

Warung Lamongan Lalapan 07

1. Deskripsi Project
Website Pemesanan dan Pengelolaan Menu pada Warung Lamongan Lalapan 07 merupakan website yang dikembangkan untuk membantu proses pemesanan makanan dan minuman, pengelolaan menu, transaksi pembayaran, serta pencatatan riwayat transaksi.

2. Tujuan Project
Membantu proses pelayanan pemesanan makanan dan minuman agar lebih terstruktur serta memudahkan pengelolaan transaksi.

3. Fitur Website
- Login dan membuat akun pengguna
- Dashboard
- Pengelolaan kategori menu
- Tambah, edit, dan hapus menu
- Upload gambar menu
- Pengaturan status ketersediaan menu
- Pemesanan makanan dan minuman
- Pilihan makan di tempat dan bungkus
- Pilihan varian ayam dada dan paha
- Pembayaran tunai dan transfer/QRIS
- Perhitungan kembalian
- Riwayat transaksi
- Cetak struk transaksi

4. Teknologi
- PHP 
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap 5.3.3
- SweetAlert2

5. Progres Tahap 1
- Melakukan analisis kebutuhan website Warung Lamongan Lalapan 07.
- Menyusun daftar kebutuhan dan fitur website.
- Merancang struktur database yang terdiri dari tabel users, kategori, menu, transaksi, dan detail_transaksi.
- Membuat struktur folder dan file project menggunakan PHP.
- Membuat konfigurasi dan koneksi database MySQL.
- Membuat halaman login beserta fitur autentikasi pengguna.
- Membuat dashboard awal website.
- Membuat sidebar dan navigasi antarhalaman.
